Trust Boundaries

Monitoring Methodology

Five Concepts

Trust & Accuracy Model

  • Availability: Can the runner reach the endpoint over HTTPS?
  • Accessibility: Can the public resource or document be opened?
  • Freshness: Did a dataset update per its documented release calendar?
  • Change Detection: Did ETag, Last-Modified, or SHA-256 change?
  • Factual Accuracy: Not verified. HTTP 200 never proves content accuracy.
Definitions

Status Classification

  • Online Expected HTTP status within timeout.
  • Issues Single-run failure or unexpected status; awaiting confirmation.
  • Unavailable Confirmed across 2+ consecutive scheduled runs.
  • WAF Restricted Edge WAF blocked cloud-IP automated checks.
  • Not Checked Registered source awaiting initial observation.
Responsible Probing

Safety & Ethics

GovSource Watch monitors public .gov.ph endpoints only. It respects robots.txt, enforces 2-second per-domain delays, never crawls recursively, never bypasses WAFs or authentication, and never stores HTML response bodies.

Complementing BetterGovPH
